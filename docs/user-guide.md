# 密小本 PassVault 使用指南

> 零知识密码管理 —— 主密码不上传，数据加密后仅你可读。账号数据在网页、浏览器插件、手机 App 之间自动同步。

## 一、密小本是什么

密小本是一个**注册制**的密码管理工具：你注册一个账号，把各类网站的账号密码存进去，需要时一键复制，再也不用记忆或翻备忘录。

它的核心特点：

- **零知识加密**：所有密码在你的设备上用你的主密码加密后才上传，服务器上只有密文，任何人（包括我们）都看不到你的明文密码；
- **多端互通**：网页版、浏览器插件、安卓 App 登录同一账号，数据实时同步；
- **完全免费**。

> ⚠️ **重要**：你的数据由主密码加密，**主密码一旦忘记，所有数据将永久无法找回**（没有任何人能帮你重置）。请务必牢记主密码。

## 三、注册与登录

### 注册

1. 打开任意一端，点击「注册」；
2. 设置**用户名**：3-32 位，只能是字母、数字、下划线；
3. 设置**主密码**：至少 8 位，这是加密你所有数据的唯一钥匙；
4. 再次输入确认，点击注册。

> ⚠️ 再次提醒：**忘记主密码 = 所有数据永久丢失，无法找回**。请设置一个你确定能记住的密码。

### 登录

输入用户名和主密码即可。登录后数据在本地解锁；点「锁定」后需要重新输入主密码才能查看。

## 五、数据安全

- **管理员也看不到你的密码**：下面是官方管理后台的真实界面——只能看到账号状态等基础信息，没有任何一条密码内容。因为所有密码在你的设备上用主密码加密后才上传，解密只发生在你自己的设备上，服务器自始至终只有密文。

![管理端界面：仅账号状态等基础信息，无任何密码内容](image/管理端.png)

- **请求日志里也只有密文**：服务端的接口请求记录（下图）同样只能看到一串串加密数据，看不到你在存什么密码、发给哪个网站；

![服务端请求日志：仅密文，无任何明文](image/管理端请求日志截图.png)

- 就算服务器数据全部泄露，泄露的也只是密文，没有你的主密码谁都解不开；
- 也是因为这套加密，**主密码丢失无法找回**：系统没有任何后门或「找回密码」入口。这既是我们的限制，更是对你数据最大的保护。

## 六、常见问题

**Q：忘记主密码怎么办？**

A：非常抱歉，数据采用零知识加密，主密码不存储在任何地方，**忘记即永久丢失，无法找回**。只能重新注册新账号。

**Q：iPhone / iOS 怎么用？**

A：目前 iOS 暂无独立客户端，直接用 **[网页版]({{H5_URL}})**，体验一致。

**Q：我的密码存在你们服务器上，安全吗？**

A：服务器只存储**加密后的密文**。加密和解密都发生在你自己的设备上，密钥由你的主密码派生，主密码不会发送给服务器。即使服务器数据全部泄露，没有你的主密码也无法解出任何一条密码。

**Q：提示「操作频繁」？**

A：为防止恶意攻击，注册、登录等操作有频率限制，稍等一分钟后重试即可。

**Q：插件安装后浏览器提示「请停用开发者模式扩展」？**

A：这是因为插件尚未上架商店、以开发者模式加载。不影响正常使用，点击保留即可；上架后我们会提供一键安装版本。
